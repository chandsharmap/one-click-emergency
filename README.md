# 🚨 One-Click Emergency System

**Medical Emergency One-Click Alert System** - A revolutionary web-based emergency response platform that enables instant medical assistance with a single click.

## 🎯 Live Demo

**[🔗 LIVE SYSTEM](https://chandsharmap.github.io/one-click-emergency/)**

---

## ✨ Features

### 🔐 Authentication System
- **Secure Login & Signup**
- User account creation with email & phone verification
- Demo account: `demo@emergency.com` / `demo123`
- Data persistence using LocalStorage

### 👨‍👩‍👧 Family Management
- Add multiple emergency contacts
- Store contact information with relationships
- Quick access during emergencies

### 🏥 Medical Profile
- Blood group tracking (O+, O-, A+, A-, B+, B-, AB+, AB-)
- Medical conditions documentation
- Pre-saved emergency medical history
- Patient name and conditions stored

### 🚑 Ambulance Tracking
- Real-time ambulance location tracking
- Distance and ETA display
- One-tap ambulance acceptance
- Live ambulance status updates

### 🩸 Blood Bank Integration
- Emergency blood unit requests
- Blood group availability check
- Quick access to nearby blood banks
- Fast blood delivery coordination

### 🚨 One-Click SOS
- **Emergency activation button**
- Instant alerts to family members
- Automatic emergency services notification (911/112)
- GPS location sharing

### 📍 Location Services
- GPS coordinates capture
- Real-time location sharing
- Map view with hospital locations
- Location history

### 📞 Emergency Call System
- Direct connection to emergency services
- Call status monitoring
- Automatic family notifications
- Call recording capability

## 🚀 How to Use

### 1. **Getting Started**
```
Visit: https://chandsharmap.github.io/one-click-emergency/
```

### 2. **Create Your Account**
- Click "Sign Up"
- Enter: Name, Email, Password, Phone
- Create account and login

### 3. **Complete Your Profile**
- Go to Dashboard
- Add Family Contacts
- Save Medical Status
- Enable Location Access

### 4. **Emergency Response**
- Click the **RED SOS BUTTON**
- Select action: Call, Show Details, or Send Location
- System alerts emergency services and family
